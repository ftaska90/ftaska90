## About

I build and experiment with Linux desktop tools, graphics stacks, system optimization, and lightweight native utilities.

A lot of my work is shaped around a simple idea:

> **Make useful software stay fast, lightweight, and practical — even on older hardware.**

My main development environment revolves around **CachyOS, Xfce, X11, C, Bash, Mesa/Crocus, and Intel Sandy Bridge graphics**.

## Development Lab

```text
OS       CachyOS x86_64
Desktop  Xfce / X11
CPU      Intel Core i3-2350M
GPU      Intel HD Graphics 3000 / Sandy Bridge GT2
Graphics Mesa / Crocus / i915
```

This older machine is intentionally part of the development process: if a tool can stay responsive here, it has a good chance of staying lightweight elsewhere too.
